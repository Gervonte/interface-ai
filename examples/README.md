# Contract fixtures

`primary-savings.contract.json` is a complete, authored example for format-v1 validation and review. It represents the **planned full staff portal** (Member Search → Member Overview → Account Inquiry → Account Details), not the smaller INT-002/INT-003 compatibility fixture.

Its sentinel source-run UUID and event sequences are test metadata. It was not generated by a real discovery run and is not assessment evidence or an artifact to execute as a confirmed capability. The later builder must derive and verify a real artifact from confirmed run events. Tests load this example through the public parser and validate real input/output values against its embedded schemas. See [CONTRACTS.md](../docs/CONTRACTS.md).

The [current](discovery-current.json) and [available](discovery-available.json) discovery request examples are explicit caller inputs for INT-023. They declare field meanings/types and account criteria, not a route, expected balance, or saved capability. The worker never imports these presets. [Usage](../docs/GOAL_OUTPUTS.md).
